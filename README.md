# Mis Finanzas

Aplicación web local para control de finanzas personales: ingresos, gastos, deudas y ahorro.

## Uso

Abre `index.html` en el navegador. No requiere instalación, servidor ni conexión a internet.

## Características

- **Resumen**: balance total, KPIs del mes, gráfica de ingresos vs. gastos (últimos 6 meses) y gastos por categoría.
- **Transacciones**: registro de ingresos y gastos por categoría, con historial filtrable.
- **Deudas**: seguimiento de deudas propias y de terceros, con abonos parciales.
- **Ahorro**: metas de ahorro con aportes y barra de progreso.
- **Ajustes**: selección de moneda, exportar datos a JSON, borrar todos los datos.

## Datos

Todo se guarda en `localStorage` del navegador — nada se envía a ningún servidor. Usa el botón "Exportar datos" en Ajustes para hacer respaldo en JSON.
